# 10-Step-Dungeon

## High Concept
10 Step Dungeon is a 3D, isometric puzzle game where the player takes on the role of an adventurer attempting to escape a mysterious dungeon. 

Each room will contain a collection of objects, obstacles, and environmental challenges for the player to overcome. The player must reach the end of each room within 10 "steps" or less, unless they want to suffer the curse of the dungeon. Make each action count, as they count towards a step.
